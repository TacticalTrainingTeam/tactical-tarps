# Repair Tarp

Adds the ability for a player carrying a repair tarp item in their inventory to construct an object via an ACE self interaction.

Unlike the other tarps, the repair tarp is only available in black. On deploy it spawns a default set of
tool props (wrench, pliers, screwdriver, gloves) around itself as inert decoration; these are created without
simulation so they carry no physics/AI cost.
