# Shelter Tarp

Adds the ability for a player carrying a shelter tarp item in their inventory to construct a shelter via an ACE self interaction.

- Green: A-frame tent (`Land_TentA_F`)
- Green (IR Cover): infrared-masking cover (`Land_IRMaskingCover_02_F`, requires Apex)
- Yellow: open cloth canopy (`Land_ClothShelter_01_F`, requires Apex)
- Blue: abandoned boat cover (`Land_Boat_03_abandoned_cover_F`, requires Apex)

The shelter tarps have no gameplay effect beyond providing a physical shelter object.
