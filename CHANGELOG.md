# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.5.0] - 2026-08-24

### Added

- Zeus Enhanced (ZEN) compatibility

## [1.4.0] - 2026-08-19

### Added

- Repair Tarp — creates an ACE Repair Facility

### Changed

- Consolidated redundant stringtable entries
- Improved Arsenal tab code

## [1.3.1] - 2026-08-04

### Changed

- Reduced mod size by ~50%

## [1.3.0] - 2026-08-03

### Improved

- Grasscutter selection

## [1.2.1] - 2026-08-03

### Added

- Translations

## [1.1.1] - 2026-08-02

### Fixed

- Hazmat tarp fixes and improvements

## [1.1.0] - 2026-08-02

### Added

- 3D placement of the tarp, similar to ACE Fortify

## [1.0.0] - 2026-07-31

### Added

- Initial release: Signal, Medic, Drone, Hazmat, and Repair tarps
