# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.7.1] - 2026-11-01

### Changed

- New logo, icon set and Steam Workshop image
- Bumped GitHub Actions dependencies (checkout, github-releases-to-discord)

## [1.7.0] - 2026-10-29

### Added

- Optional per-item build time offset in the `tarpItems` entries of the deployable tarp framework
- Shelter Tarp — deploys an A-frame tent (Land_TentA_F, green), an infrared-masking cover (Land_IRMaskingCover_02_F, green, requires Apex), an open cloth canopy (Land_ClothShelter_01_F, yellow, requires Apex) or a boat cover (Land_Boat_03_abandoned_cover_F, blue, requires Apex). The Apex variants are provided by the optional shelter_apex sub-addon and are skipped when Apex is not loaded

## [1.6.1] - 2026-10-18

### Fixed

- ACE interaction point of deployed tarps sits slightly above the tarp, so it stays reachable when the tarp is placed below a floor
- Arsenal button is now localized and missing stringtable entries were added

## [1.6.0] - 2026-09-18

## [1.5.0] - 2026-08-24

### Added

- Zeus Enhanced (ZEN) compatibility

## [1.4.0] - 2026-08-19

### Added

- Repair Tarp — creates an ACE Repair Facility

### Changed

- Consolidated redundant stringtable entries
- Improved Arsenal tab code

## [1.3.1] - 2026-08-04

### Changed

- Reduced mod size by ~50%

## [1.3.0] - 2026-08-03

### Improved

- Grasscutter selection

## [1.2.1] - 2026-08-03

### Added

- Translations

## [1.1.1] - 2026-08-02

### Fixed

- Hazmat tarp fixes and improvements

## [1.1.0] - 2026-08-02

### Added

- 3D placement of the tarp, similar to ACE Fortify

## [1.0.0] - 2026-07-31

### Added

- Initial release: Signal, Medic, Drone, Hazmat, and Repair tarps
